AudioFX Station — UML

Структура классов, паттерн Decorator в цепочке обработки аудио и последовательность взаимодействия

2. Цепочка обработки аудио (паттерн Decorator)

Каждый провайдер оборачивает предыдущий через поле source : ISampleProvider. Сигнал течёт слева направо к устройству вывода.

flowchart LR

    EQ["EqualizerSampleProvider
5-полосный EQ + HighPass"]
    CP["CompressorSampleProvider
Threshold / Ratio / Attack / Release"]
    RV["ReverbSampleProvider
Comb + AllPass"]
    VS["VarispeedSampleProvider
Speed (Slowed / Normal / Nightcore)"]
    VO["VolumeSampleProvider
Master Volume / Mute"]
    SP["SpectrumSampleProvider
FFT-анализ для визуализации"]
    SW["SampleToWaveProvider"]
    OUT["🔊 WaveOut
(аудио-выход)"]

    A --> EQ --> CP --> RV --> VS --> VO --> SP --> SW --> OUT

3. Последовательность: открытие файла и воспроизведение

Как классы взаимодействуют в рантайме при загрузке аудио и запуске проигрывания.

sequenceDiagram
    autonumber
    actor U as Пользователь
    participant MW as MainWindow
    participant FD as StorageProvider
(OpenFilePicker)
    participant AF as AudioFileReader
    participant CH as Цепочка ISampleProvider
(EQ→Comp→Reverb→Varispeed→Volume→Spectrum)
    participant WO as WaveOut
    participant T as DispatcherTimer

    U->>MW: OpenAudio_Click()
    MW->>FD: OpenFilePickerAsync()
    FD-->>MW: выбранный путь файла
    MW->>AF: new AudioFileReader(path)
    MW->>CH: собрать цепочку провайдеров (Decorator)
    MW->>WO: Init(new SampleToWaveProvider(spectrum))
    MW->>AF: LoadWaveform() → waveformPeaks
    MW-->>U: DrawWaveform() + обновить UI

    U->>MW: Play_Click()
    MW->>WO: Play()
    loop каждый аудио-буфер
      WO->>CH: Read(buffer)
      CH->>AF: Read() (источник цепочки)
      AF-->>CH: сэмплы
      CH-->>WO: обработанные сэмплы + spectrumValues
    end
    T->>MW: Tick (100 мс) → UpdateTimeline()
    MW-->>U: playhead + PositionText + DrawSpectrum()

4. Взаимодействие окон эффектов

MainWindow открывает модальные окна, передавая ссылку на соответствующий провайдер; окно настраивает его в реальном времени.

flowchart LR
    MW["MainWindow"]
    EQW["EqualizerWindow"]
    CPW["CompressorWindow"]
    RVW["ReverbWindow"]
    EQP["EqualizerSampleProvider"]
    CPP["CompressorSampleProvider"]
    RVP["ReverbSampleProvider"]

    MW -->|"new EqualizerWindow(equalizer).Show()"| EQW
    MW -->|"new CompressorWindow(compressor).Show()"| CPW
    MW -->|"new ReverbWindow(reverb).Show()"| RVW

    EQW -->|"SetFiveGains()"| EQP
    CPW -->|"SetSettings() / читает GainReduction"| CPP
    RVW -->|"SetMix()"| RVP

    CPP -. "GainReduction (обратная связь → метр)" .-> CPW
